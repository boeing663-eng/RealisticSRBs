# Contributing to RealisticSRBs

Thanks for your interest in RealisticSRBs!

## Reporting bugs
Please open an issue on GitHub and describe the problem.

## Suggesting features
Open an issue describing the feature you'd like to see.

## Code contributions
Pull requests are welcome, but please explain your changes.

## Requirements
- Keep changes compatible with KSP1.
- Test changes before submitting pull requests.
