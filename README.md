# RealisticSRBs

RealisticSRBs is a mod for **Kerbal Space Program 1 (KSP1)** that adds size-based gimbal ranges to supported stock solid rocket boosters (SRBs).

The goal of the mod is to give solid rocket boosters different steering capabilities based on their size. Smaller boosters receive a smaller gimbal range, while larger boosters receive a greater range.

## Features

- **Small SRBs:** 3° gimbal range
- **Medium SRBs:** 5° gimbal range
- **Large SRBs:** 7° gimbal range
- Automatically detects supported stock solid rocket boosters.
- Generates ModuleManager configuration patches to apply the appropriate gimbal ranges.
- Designed to work with the stock KSP1 parts system.

## Installation

Download the latest available release from the [GitHub Releases page](https://github.com/boeing663-eng/RealisticSRBs/releases) and follow the installation instructions included with the download.

Make sure you have the required version of ModuleManager installed.

RealisticSRBs currently supports stock solid rocket boosters only. Compatibility with additional parts or third-party mods is not guaranteed.
