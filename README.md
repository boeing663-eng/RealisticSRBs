# RealisticSRBs

A Kerbal Space Program 1 mod that adds size-based gimbal ranges to supported stock solid rocket boosters (SRBs).

## Features
- Automatic SRB detection
- Small boosters: 3° gimbal
- Medium boosters: 5° gimbal
- Large boosters: 7° gimbal

## Installation
Download the latest ZIP from the [Releases](../../releases) page and follow the included installation instructions.
